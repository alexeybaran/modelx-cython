# Native execution beneath ordinary Spaces

Eligible numeric calculation paths use native internal entries by default. Public
Cell signatures, ordinary policy Spaces, authoritative cached results, formula
ownership and supported dynamic fallback remain. No model-name eligibility is used.

The qualified package includes native numeric dependency execution and PV-loop
indices, lazy Space-owned numeric value storage, owned typed Data reads, guarded
category comparisons and connected object-key lookup acceleration. Validity flags
still control reads: a cache result is readable only after successful completion.

Unsupported object-heavy graphs retain the prior implementation. Object-key
acceleration retains the original dictionary and its canonical result objects;
changed hash/equality or unsupported domains disable the derived index. Public
Enum/string objects and mutation/rebinding checks remain supported.

For development comparison only, set both MX_CY_INTEGRATED_NATIVE=0 and
MX_CY_CONNECTED_NATIVE=0 before translation to retain the accepted pre-package
path. Setting both to 1 explicitly is equivalent to the default. Mixed switch
settings are internal diagnostics, not an author-facing model API.

Windows qualification (one warmup, three interleaved rounds) reduced calculation
time by 9.4% for adjusted MYGA with expensive table operations executed through
helpers, and by 24.3% for original BasicTerm_SC. Populations were 3,500 and 50,000
policies respectively, one supplied scenario each, using in-model aggregation and
including policy binding. Original MYGA keeps the accepted executable source and
shows no resolved regression. Public-report regression in the broader initial
index selection was removed by selecting connected dependencies only.

These are whole-package effects, not independently additive component savings.
Previous-compiler parity remains unproven: the measured package is about 5.0x
slower on MYGA and 2.34x on BasicTerm. No immutable-input snapshot shortcut,
prepared-policy API, batch API, formula interpreter or collect() is introduced.

Evidence: local modelx-benchmark-toolkit repository, CONNECTED_NATIVE_REPORT.md,
evidence/connected-native-01; measured revisions e465e52 / d6d2adf, timing runner
f099b6b. Default activation is checked against those generated sources before
integration. No push is part of this change.
